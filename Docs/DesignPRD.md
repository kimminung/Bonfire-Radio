# 불멍 라디오 (Bonfire Radio) — 디자인 PRD

- 문서 버전: v1.0 (2026-09-29)
- 플랫폼: Apple Vision Pro (visionOS 27)
- 작성 목적: 한국에서 Vision Pro를 착용한 사용자들이 **한 사람(방장)이 진행하는 라디오/음악 방송**을 모닥불 주위에 둘러앉아 함께 듣는 공간 경험을 정의한다.

---

## 1. 제품 비전

> "밤하늘 아래 모닥불에 둘러앉아, 한 사람의 목소리와 음악을 함께 듣는다."

- 방장은 방을 만들고 목소리와 음악을 송출한다.
- 최대 8명(방장 포함)이 스카이돔 이머시브 공간에 원형으로 앉는다.
- 중앙의 **모닥불이 비주얼라이저**가 되어 음악과 목소리에 맞춰 살아 움직인다.
- 누구나 모닥불에 아이템을 던져 불의 색을 바꿀 수 있다(참여감).

## 2. 타깃 사용자

| 페르소나 | 니즈 | 핵심 순간 |
|---|---|---|
| 방장 (DJ/진행자) | 친구·팬들에게 라디오처럼 이야기하며 음악을 틀고 싶다 | 방 생성 → "ON AIR" 표시 → 첫 곡 재생 |
| 청취자 | 편하게 누군가의 방송을 들으며 함께 있는 느낌을 받고 싶다 | 초대 수락 → 자리 배정 → 불꽃이 음악에 반응하는 것을 보며 아이템 던지기 |
| 함께 있는 친구들(같은 방) | 한 공간에서 여러 대의 Vision Pro로 같은 불을 본다 | 근처 공유(Nearby SharePlay)로 즉시 참여 |

## 3. 핵심 사용자 시나리오

### 3.1 방장 플로우
1. 앱 실행 → 로비 윈도우 표시.
2. **"방 만들기"** 탭 → SharePlay 활성화(FaceTime 통화 중이면 즉시 시작, 아니면 초대 시트 표시).
3. 세션이 시작되면 자동으로 **이머시브 스카이돔**이 열리고 방장은 모닥불 정면의 "방장 좌석"에 앉는다.
4. 컨트롤 패널(윈도우)에서 음원 선택: **데모 트랙 / 스트림 URL / 내 파일**.
5. ▶ 재생 → 모닥불이 음악에 반응. 방장은 FaceTime 음성으로 진행(DJ 멘트).
6. 방장 패널에만 "ON AIR", 송출 컨트롤, 불 색 초기화 버튼이 존재한다.

### 3.2 청취자 플로우
1. FaceTime/메시지 초대 또는 근처 공유 초대 수락 → 앱이 자동 실행되어 세션에 참가.
2. 방장이 이머시브를 열면 "함께 들어가기" 안내 후 같은 스카이돔으로 진입(강제하지 않음).
3. 원형 좌석 중 빈 자리에 배정. 앞에 놓인 **아이템 바구니**에서 물건을 잡아 모닥불에 던질 수 있다.
4. 청취자 패널: 현재 곡 정보, 방장 이름, "청취자 모드(마이크는 방장만 사용)" 안내, 던지기 가이드.

### 3.3 혼자 불멍 (테스트/솔로 모드)
- SharePlay 없이 같은 공간을 열어 데모 트랙과 마이크에 반응하는 불을 즐긴다. 개발 검증에도 사용.

## 4. 공간 구성 (이머시브)

```
                 ⭐  밤하늘 스카이돔 (반경 60m)  ⭐
      좌석7            좌석8(방장)             좌석1
   좌석6                 🔥                        좌석2
      좌석5            좌석4                  좌석3
                 ⬛ 어두운 지면 디스크 (반경 12m)
```

- **원형 배치**: 반경 2.4m, 8석. 방장 좌석은 z축 + 방향(정면). 모든 좌석은 모닥불(원점)을 바라본다.
- **스카이돔**: 짙은 남색 → 지평선 근처 따뜻한 잔광 그라데이션, 절차적 별 필드. 은하수 느낌의 미세한 밝은 띠.
- **지면**: 무광 어두운 흙색 디스크, 모닥불 조명을 받아 은은하게 밝아진다.
- **모닥불**: 돌 12개로 둘러싼 원(반경 0.55m), 장작 5개 티피(원뿔) 구조, 그 위 불꽃.
- **아이템 바구니**: 각 참가자의 정면 0.6m, 높이 0.75m 지점에 작은 접시. 던질 아이템 3개가 놓여 있고 던지면 2초 후 리스폰.

## 5. 모닥불 비주얼라이저 디자인

### 5.1 레이어 (RealityKit ParticleEmitterComponent 5중 구성)

| 레이어 | 역할 | 형태/움직임 | 오디오 매핑 |
|---|---|---|---|
| 코어 불꽃 | 밝고 빠른 중심 화염 | 원뿔 이미터, 위로 가속, 노이즈 난류, 수명 0.5~0.8s, 끝에서 축소 | 저역(베이스) → 출생률·속도, 비트 → 순간 확장 |
| 외곽 불꽃 | 크고 느린 혀 모양 화염 | 더 큰 파티클, 낮은 출생률, 강한 노이즈 | 중역 → 크기, RMS → 높이 |
| 불씨(스파크) | 위로 떠오르는 작은 점 | 긴 수명 2~4s, 소용돌이·노이즈, 반짝임 | 고역(트레블) → 출생률 |
| 연기 | 불 위 1m부터 회색 연무 | 매우 느림, 낮은 불투명도, 큼 | 볼륨↓ 시 상대적으로 두드러짐 |
| 열기 왜곡 대체 | 불 주변 옅은 광륜 | 낮은 알파, 부드러운 확산 | RMS |

- **동적 조명**: 모닥불 위치의 PointLight가 불의 색을 띠고, 저역 에너지와 노이즈로 깜빡인다(장작·돌·지면·참가자 근처 소품을 비춘다).
- **장작 자체 발광**: 장작 표면 안쪽에 에미시브 빨간/주황 재질로 "달궈진 숯" 느낌.

### 5.2 오디오 → 시각 매핑 규칙
- 분석 주기 ~30Hz. 밴드: 저역(40–200Hz), 중역(200–2kHz), 고역(2k–8kHz), RMS, 비트(에너지 플럭스 임계 초과).
- 매핑은 **스무딩(어택 빠름/릴리즈 느림)** 적용. 음악이 없을 때도 기본 idle 노이즈로 자연스러운 흔들림 유지.
- 방장 목소리(솔로 모드/마이크 사용 가능 시)는 중역 밴드에 합산되어 불꽃 혀가 말에 맞춰 흔들린다.

### 5.3 불 색 팔레트 (던지기 아이템)

화학 시간의 불꽃 반응을 모티프로 한다. 아이템은 손바닥 크기 소품이며, 이름/색/설명을 갖는다.

| 아이템 (한글) | 모티프 | 불 색 (코어 → 외곽) | 불씨 색 |
|---|---|---|---|
| 소금 한 줌 | 나트륨 | 밝은 노랑 → 주황 | 금색 |
| 구리 조각 | 구리 | 청록 → 초록 | 연두 |
| 리튬 돌 | 리튬 | 진홍 → 붉은 자주 | 핑크 |
| 칼륨 가루 | 칼륨 | 연보라 → 라벤더 | 흰 보라 |
| 붕산 결정 | 붕소 | 연두 → 에메랄드 | 민트 |
| 스트론튬 알 | 스트론튬 | 선홍 → 다홍 | 주홍 |
| 마그네슘 리본 | 마그네슘 | 백색 → 하늘빛 백색 | 흰색 |
| 별가루 | 판타지 | 시안 → 남보라 | 하늘색 |
| (기본) 장작불 | — | 노랑-흰 → 주황 → 붉은 | 주황 |

- 던진 아이템이 불에 닿으면: **0.3초 섬광 버스트** → **1.5초 동안 색이 크로스페이드** → 새 색으로 유지. 90초 후 서서히 기본 장작불로 돌아온다(방장이 "불 색 초기화" 가능).
- 여러 명이 연달아 던지면 마지막 던진 색이 우선. 동시 던지기는 순번(seq) 큰 값이 우선.

## 6. UI (윈도우)

### 6.1 로비
- 앱 로고(불꽃 심볼), 한 줄 카피 "모닥불에 둘러앉아 함께 듣는 라디오".
- 버튼: **방 만들기 (SharePlay)**, **혼자 불멍**, 하단 작은 텍스트로 상태(FaceTime 통화 여부, 참가 가능 여부).
- 세션 초대가 감지되면 자동으로 방 화면으로 전환.

### 6.2 방 컨트롤 패널 — 방장
- 상단: "ON AIR" 배지(붉은 점 애니메이션), 방 인원 n/8.
- 음원 섹션: 세그먼트(데모 트랙 / 스트림 URL / 내 파일), 재생·일시정지, 볼륨, 현재 곡.
- 모닥불 섹션: 현재 불 색 칩, "불 색 초기화", "불 세기" 슬라이더(기본 1.0).
- 공간 섹션: "스카이돔 열기/닫기", 몰입도(프로그레시브/풀).
- 종료: "방송 끝내기".

### 6.3 방 컨트롤 패널 — 청취자
- 상단: 방장 이름 + "방송 중", 인원.
- 현재 곡, 볼륨(로컬).
- 안내 카드: "이 방에서는 방장만 마이크와 음악을 송출합니다. FaceTime 마이크를 꺼두면 더 좋아요."
- 던지기 가이드: "앞의 바구니에서 물건을 잡아 모닥불에 던져보세요."
- "공간 나가기".

### 6.4 이머시브 내 오너먼트
- 모닥불 위 1.6m에 작은 **Now Playing 라벨**(곡명, 방장 이름) — 빌보드, 은은한 글래스.
- 아이템에 시선을 두면 이름 툴팁이 뜬다(HoverEffect).

## 7. 인터랙션

- **던지기**: 아이템을 손으로 잡아(직접 제스처) 던지면 관성이 유지되어 날아간다. 시선+핀치 간접 제스처로 잡아 끌어 놓아도 동작한다. 불의 트리거 볼륨에 들어가면 색 변화.
- **폴백 버튼**: 손 추적이 어려운 상황을 위해 패널에 "던지기" 버튼 제공(아이템 선택 후 자동 포물선 발사).
- **자리 이동 없음**: 좌석은 시스템(SharePlay Spatial Template)이 배치. 사용자는 자연스럽게 머리를 돌려 서로를 본다.

## 8. 사운드 디자인
- 모닥불 앰비언스(장작 타는 소리)는 공간 오디오로 모닥불 위치에서 재생, 볼륨 낮음(음악 대비 -18dB).
- 던지기 성공 시 "치익—펑" 짧은 효과음 + 색이 바뀌는 순간 반짝임 소리.
- 음악은 모닥불 위치에서 나오는 것처럼 살짝 공간화(사운드 스테이지 큼).

## 9. 편안함·접근성
- 불꽃·연기 모션은 시야 중앙에서 작게 시작, 갑작스러운 대형 플래시 금지(버스트 최대 밝기 제한).
- 별 필드·스카이돔은 정지(멀미 방지). 카메라 이동 없음.
- 몰입도 프로그레시브 지원(Digital Crown으로 현실 공간 노출).
- 텍스트는 Dynamic Type, 색 대비 4.5:1 이상, 모든 컨트롤에 VoiceOver 라벨.
- 광과민성: "불꽃 깜빡임 줄이기" 토글(비트 반응 완화).

## 10. 온보딩·권한 문구
- 마이크: "방장의 목소리에 맞춰 모닥불이 반응하도록 마이크 입력 크기를 측정합니다. 녹음은 저장되지 않습니다."
- SharePlay: 시스템 기본 초대 UI 사용.

## 11. 성공 지표 (v1)
- 방 생성 → 첫 참가자 입장까지 60초 이내 성공률 80%+.
- 세션 평균 체류 15분+.
- 세션당 던지기 3회+.

## 12. 알려진 플랫폼 제약 (디자인에 반영됨)
1. **다른 앱의 소리 캡처 불가**: visionOS 샌드박스는 타 앱/시스템 오디오를 가로챌 수 없다. 따라서 음악은 **이 앱 내 플레이어**(데모 트랙, 스트림 URL, 방장 파일)로 재생한다. "내가 쓰는 앱플레이어 소리 송출"은 이 앱의 플레이어를 사용하는 방식으로 대체된다.
2. **FaceTime 마이크 제어 불가**: SharePlay의 음성은 FaceTime이 담당하며 앱이 다른 참가자의 마이크를 끌 수 없다. 앱은 "청취자 모드" 안내와 방장 전용 송출 컨트롤로 **송출 권한(음악·불 초기화)** 을 방장에게 제한한다. 서버 강제형 마이크 권한은 v2(자체 오디오 서버)에서 다룬다.
3. **공간 페르소나 표시 인원**: 시스템이 동시에 배치하는 공간 페르소나 수에 한계가 있을 수 있다(HIG 권고 5명). 좌석은 8석을 정의하되, 초과 인원은 FaceTime 창으로 보일 수 있음을 안내한다.
4. **FaceTime 통화 중 앱 마이크 접근 제한**: 통화 중에는 앱이 마이크를 직접 읽지 못할 수 있어, 목소리 반응은 솔로 모드에서 확실히 동작하고 SharePlay 중에는 음악 반응이 중심이 된다.

## 13. 비범위 (v1)
- 녹음/다시 듣기, 채팅, 방 목록/공개 방 탐색, 결제, Apple Music 카탈로그 검색(v2 후보), 로컬 파일을 다른 참가자에게 전송(v2).
